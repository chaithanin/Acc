# ขอเชื่อมต่อข้อมูลจาก Mango — ร่างสำหรับส่ง Mango Consultant

เอกสารนี้คือคำขอที่ส่งได้เลย พร้อมเหตุผลว่าทำไมถึงขอสิ่งเหล่านี้ ไม่ใช่สิ่งอื่น

## ทำไมต้องขอ

ฝั่งอสังหาริมทรัพย์ (`production.re`) เชื่อมต่อได้แล้วด้วย session login และใช้งานได้จริง
แต่ฝั่งบัญชี (`production.anywhere` + `production.service`) ติดที่ **token ผูกกับ session
ของเบราว์เซอร์** ซึ่งไม่มีทางได้มาอย่างถูกต้องจากฝั่งเซิร์ฟเวอร์ และต่อให้ได้มาก็หมดอายุใน 1 ชั่วโมง

การไล่แกะกลไกนี้ต่อไปไม่ใช่คำตอบที่ถูก — ระบบมีหน้า API Tokens อยู่แล้ว
(`rex_settings/api_tokens` มี token active อยู่ 1 ตัว สร้างเมื่อ 24/08/2026) แปลว่ามี API
อย่างเป็นทางการ แค่ยังไม่มีเอกสารฝั่งผู้ใช้

---

## ร่างข้อความ

> เรียน ทีมงาน Mango Consultant
>
> บริษัท ไชยธนินทร์ จำกัด (MG1) ต้องการเชื่อมต่อข้อมูลจากระบบ Mango
> (`chaithanin.mangoanywhere.com`) ไปยังระบบรายงานผู้บริหารภายในของบริษัท
> เป็นการ **อ่านอย่างเดียว** ไม่มีการเขียนกลับ รบกวนขอความอนุเคราะห์ดังนี้ครับ
>
> **1. เอกสาร REST API สำหรับ token ที่สร้างจากหน้า `rex_settings/api_tokens`**
>
> - base path และวิธีส่ง token (header ชื่ออะไร)
> - รายการ endpoint พร้อม schema ของผลลัพธ์
> - วิธีระบุบริษัท (maincode) ในคำขอ — ทางบริษัทมี 6 บริษัทในระบบ (MG1–MG6)
>   และต้องการข้อมูลแยกรายบริษัท
>
> **2. ข้อมูลที่ต้องการเข้าถึง** โดยเทียบกับหน้าจอที่ใช้อยู่:
>
> | ต้องการ | หน้าจอ/ข้อมูลที่ตรงกัน |
> | --- | --- |
> | ยอดลูกหนี้คงค้าง รายคู่ค้า และแยกตามช่วงอายุหนี้ | Dashboard — balance AR / barchart AR |
> | ยอดเจ้าหนี้คงค้าง รายคู่ค้า และแยกตามช่วงอายุหนี้ | Dashboard — balance AP / barchart AP |
> | ยอดคงเหลือธนาคาร แยกเงินฝากกับหนังสือค้ำประกัน | Dashboard — bank all |
> | สมุดรายวันทั่วไป / งบทดลอง | โมดูล GL |
> | ทะเบียนใบสั่งซื้อและยอดผูกพัน | โมดูล PO |
> | งบประมาณต้นทุนโครงการ และต้นทุนที่เกิดขึ้นจริง | โมดูลที่เกี่ยวข้อง |
>
> **3. ขอบเขตและข้อจำกัด**
>
> - token หนึ่งใบเข้าถึงได้กี่บริษัท และจำกัดตามสิทธิ์ผู้ใช้หรือไม่
> - rate limit และวิธีแบ่งหน้า (pagination)
> - อายุของ token และวิธีต่ออายุ
> - มี webhook หรือ event แจ้งเตือนเมื่อข้อมูลเปลี่ยนหรือไม่
>
> **4. ฝั่ง `production.re`** ปัจจุบันทางบริษัทดึงข้อมูลผ่าน endpoint ภายใน
> (`re/reportx/All_Transaction_Data`) ด้วยบัญชีผู้ใช้ ซึ่งใช้งานได้ดี รบกวนสอบถามว่า
>
> - วิธีนี้เป็นที่ยอมรับหรือไม่ หรือควรเปลี่ยนไปใช้ API token แทน
> - endpoint เหล่านี้มีโอกาสเปลี่ยนรูปแบบตอนอัปเกรดหรือไม่ และจะแจ้งล่วงหน้าได้หรือไม่
>
> **5. หากยังไม่มี REST API ครบตามข้างต้น** ขอทางเลือกอื่นแทนได้หรือไม่ เช่น
>
> - read-only database view
> - scheduled export เป็น CSV/Parquet ขึ้น SFTP หรือ object storage วันละครั้ง
>
> ทั้งนี้บริษัทจะใช้ **service account แยกต่างหาก** สำหรับการเชื่อมต่อ ไม่ใช้บัญชีพนักงาน
> และจะแจ้งช่วงเวลาที่ดึงข้อมูลให้ทราบ เพื่อไม่ให้ถูกมองว่าเป็น traffic ผิดปกติ
>
> ขอบคุณครับ

## สิ่งที่ควรขอจาก IT ภายในควบคู่กัน

**service account สำหรับการเชื่อมต่อ** — สิทธิ์อ่านครบทุกโครงการและทุกบริษัทที่ต้องรายงาน
ห้ามใช้บัญชีพนักงาน เพราะ Mango บันทึก audit log ทุกครั้งที่เปิดเมนู การรันอัตโนมัติ
ใต้ชื่อพนักงานจะทำให้ audit trail ของคนคนนั้นใช้ตอบคำถามไม่ได้อีกต่อไป

ดู [`MANGO-RE.md`](MANGO-RE.md) และฝั่งสต็อกห้องรอเพียง API key ใบเดียว

จะได้ข้อสรุป
